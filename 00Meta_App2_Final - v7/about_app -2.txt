VULSENS & SECMOD APPLICATION – README
Version: v5 (2026-07-17)
Authors: Gallagher Re, Property Research
Repository: Internal model-testing workspace

Overview
The Vulsens & Secmod Toolkit is a modular Shiny application built for catastrophe modellers and property researchers. It provides a connected workspace to prepare, extract, analyse, and report on Vulnerability Sensitivity (Vulsens) and Secondary Modifier (Secmod) test cases across Moody’s RMS and Verisk modelling platforms.

The application is structured as a pipeline:

Input File Creation – generate standardised Location & Account files for vendor models.

Result Extraction – connect to Exposure and Result databases to retrieve loss metrics.

Secondary Modifier Analysis – run the full sensitivity workflow, customise charts, and build a gallery of results.

Cart & Reporting – collect plots and commentary, then export a polished PowerPoint, Word, or HTML report.

All modules share a unified visual language (navy/teal/amber) and a common cart system that persists per user.

Key Features
Multi‑vendor support: Moody’s RMS and Verisk (AIR)

Two test modules: Vulnerability Sensitivity and Secondary Modifiers

Interactive data validation and preview (DT tables)

Live customisation of every plot (colours, sizes, fonts, margins, labels)

One‑click Add to Cart – collect any plot with its current styling

Multi‑format reporting: PPTX, DOCX, and HTML (self‑contained)

Full R Markdown reporting for Secmod (customised HTML with all user overrides)

Persistent user carts (saved to disk)

Responsive two‑column layout with independent scrollbars and progress stepper

Technology Stack
R (4.0+) with Shiny, shinydashboard, shinyjs

Data handling: data.table, dplyr, RODBC (SQL Server)

Reporting: officer (PPTX/DOCX), rmarkdown + knitr (HTML), ggplot2

Styling: custom CSS with Font Awesome icons

Deployment: runs locally or on a Shiny Server / RStudio Connect

Defines functions to manage user‑specific carts stored as .rds files in a cart/ directory.

Code name: docx_generator.R
Location: R/
Author: Gallagher Re, Property Research
Date: 2026
What this code does:

Builds a scientific Word (.docx) report from a cart .rds file.

Creates a title page with logo, a Table of Contents (using native Word fields), and one numbered section per cart item.

Embeds each plot as a captioned figure and renders commentary as an indented block‑quote.

Adds a live page‑number footer (Page X of Y) and forces field updates on open.

Code name: function_Secmod.R
Location: R/
Author: Gallagher Re, Property Research
Date: 2026
What this code does:

Contains the core analytical functions for the Secondary Modifier workflow.

finaltable() and finaltable_allUSA() transform AAL data by classification and modifier.

indmod() generates individual modifier plots (one per modifier) across states.

STATEminmax() and Countryminmax() compute credit/penalty ranges at state and country levels.

Credit_Penalty() creates the combined bar chart showing modifiers with >10% sensitivity change.

STATE_plot() produces state‑specific plots for SFD vs COM, with helpers to save all plots as PNG.

Code name: rmd_generator.R
Location: R/
Author: Gallagher Re, Property Research

What this code does:

Knits the vulsen_report_template.Rmd into a self‑contained HTML report from a cart .rds file.

Code name: secmod_server.R
Location: server/
Author: Gallagher Re, Property Research
Date: 2026
What this code does:

The largest server module, handling all logic for the Secondary Modifier section.

Manages data upload (State AAL, Country AAL, mapping file) and calls finaltable, STATEminmax, etc.

Generates credit/penalty plots, state‑wise plots, and modifier plots, storing them in reactive values.

Includes demo data loading and report generation locks (preventing concurrent runs).

Author: Gallagher Re, Property Research
Date: 2026
What this code does:

Defines the UI for the Secondary Modifier module.

Two‑column layout: left panel contains six stage cards (Settings, Inputs, Credit/Penalty, State Sensitivity, Individual Modifier, Report).

Right panel shows the progress stepper, an info panel describing the workflow, and a tabset with the Min/Max Table, Credit/Penalty plot, State Sensitivity gallery, and Individual Modifier gallery.

Each gallery includes a collapsible “Gallery defaults” control bar and per‑plot override panels with extensive customisation options (via sec_plot_card_gallery()).

The Report stage has a “Generate Report” button and a “Download Report” button (state‑locked until generation completes).

Includes JavaScript to scroll to sections and toggle gallery panels.
