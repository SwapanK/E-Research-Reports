1. WHAT IS THE VULNERABILITY MODULE?
================================================================================
The Vulnerability Module is a single Shiny dashboard that takes you through the
whole workflow for Vulnerability Sensitivity and Secondary Modifier (Secmod)
testing on Moody's RMS and Verisk catastrophe models — from building vendor
input files, through extracting loss results from a database, to analysing
sensitivity and packaging your findings into a shareable report.

The app is organised as a pipeline, and each stage lives in its own page:

    Input File Creation  -->  Result Extraction  -->  Vulnerability
    Sensitivity / Secondary Modifier  -->  Cart & Reports

You don't have to use every stage for every task — for example, you can jump
straight into "Vulnerability Sensitivity" with your own file if you already
have extracted results, or use "Secondary Modifier" on its own with sample or
uploaded AAL data.

Everything you build up in any module — plots and written commentary — can be
sent to a shared Cart and exported together as one polished PowerPoint, Word,
or HTML report.

================================================================================
The Home page is the landing screen and gives you a quick way into any
module. It shows:
  - A hero section with a "Start a New Workflow" button (jumps to Input File
    Creation) and a "View Cart" button (shows your current item count).

4. MODULE 1 — INPUT FILE CREATION
================================================================================
PURPOSE
  Builds the standardized vendor Location and Account/Combination files that
  RMS and Verisk expect, for either the Vulnerability Sensitivity or the
  Secondary Modifier module, either from your own uploads or from the
  bundled sample data.

LEFT PANEL — STEP BY STEP
  1. Model Selection
     - Choose Vendor model family: Moody's or Verisk.
     - Choose the model version (options update automatically per vendor).
     - Choose Module: Vulnerability Sensitivity or Secondary Modifiers.

  2. Exposure Settings
     - Country code (default "US").
     - Peril and Subperil (subperil list updates based on the peril chosen).
     - Suffix — a label appended to output file names (e.g. a year/version
       tag such as "2026").
     - Building value, Contents value, and BI (Business Interruption) value
       — the exposure amounts used to build the account/combination file.

  3. Upload / Sample Input Files
     - Upload a Locations File (.csv) and a Combinations File (.csv) that
       match your chosen vendor and module, OR click "Use included sample
       files" to preview the expected format with bundled example data.
     - "Sample Locations" / "Sample Combinations" download buttons let you
       grab the raw sample CSVs to see the required column layout before
       preparing your own files.
     - Click "Create Input Files" once your settings and inputs are ready.

RIGHT PANEL
  - Input Dashboard tab: preview of the location/combination data you
    uploaded or sampled, so you can check columns and values before
    generating.
  - Output Dashboard tab: preview of the generated Location and Account
    files, each with its own download button.

TYPICAL WORKFLOW
  1. Pick platform and module.
  2. Set exposure parameters (country, peril, subperil, values).
  3. Upload your files or use the sample files.
  4. Review the input preview.
  5. Click "Create Input Files".
  6. Review the generated output preview.
  7. Download the final Location and Account files for testing.

5. MODULE 2 — RESULT EXTRACTION
================================================================================
PURPOSE
  Connects to your RMS or Verisk SQL database (via ODBC), pulls
  ExposureSet/ResultSet AAL data for one or two model versions, and writes
  out the comparison result files used by the Vulnerability Sensitivity and
  Secondary Modifier modules.

LEFT PANEL — STEP BY STEP
  1. Model Selection
     - Vendor model family (Moody's or Verisk).
     - Module (Vulnerability Sensitivity or Secondary Modifiers).
     - Number of versions to compare (1 or 2) — choosing 2 unlocks a second
       connection panel so you can compare two model runs side by side.

  2. Exposure Settings
     - Country code, Peril, Subperil, Suffix — same idea as in Input File
       Creation; these tag and organise the resulting output files.

  3. Upload / Sample Input Files
     - Upload the Vulsens/Secmod Combination file (.csv) that defines your
       classification/description columns.
     - Optionally upload a Region file (.csv) to also produce "byRegion"
       outputs.
     - Or click "Use included sample files" to try the workflow with
       bundled data; sample CSVs are downloadable for reference.

  4. Version Database Settings (one panel per version)
     - Version label and Server (defaults are suggested per vendor).
     - Click "Connect version N" to open the database connection (RMS may
       prompt for credentials).
     - Pick the Exposure Database (EDM/TSE), click "Load ExposureSet", then
       enter the PORTINFOID / ExposureSetSID.
     - Pick the Result Database (RDM/TSR), click "Load ResultSet", then
       enter the ANLSID / AnalysisResult.

  5. Extract
     - Click "Create Result Files" once both versions (or the single
       version) are configured.
     - Choose an output and click "Download" for an individual file, or
       download the consolidated ZIP package.

RIGHT PANEL TABS
  - ExposureSet / ResultSet: metadata for the databases you've connected.
  - Input Preview: your uploaded Combination and Region files.
  - Output Preview: the generated Location, State, County, and (optional)
    Region-level comparison outputs.

TYPICAL WORKFLOW
  1. Choose platform (RMS or Verisk).
  2. Choose Exposure (EDM/TSE) and Result (RDM/TSR) databases.
  3. Load ExposureSet and ResultSet for each version.
  4. Set analysis identifiers.
  5. Generate standardized outputs at Location/State/County (and optional
     Region) level.
  6. Review previews.
  7. Download individual files or the full ZIP for the next module.

6. MODULE 3 — VULNERABILITY SENSITIVITY
================================================================================
PURPOSE
  Reviews Moody's/Verisk vulnerability sensitivity outputs as responsive
  heatmaps with hover values, a fully configurable legend, a processed-data
  preview, and downloadable outputs.

LEFT PANEL — STEP BY STEP
  1. Model Configuration
     - Vendor model family, Number of model versions to compare, Country
       code, Suffix, Peril and Subperil.

  2. Input Data
     - Upload your own CSV, or click "Load Included Sample Data" to use the
       bundled example. "Moody's sample" / "Verisk sample" buttons download
       the raw sample files for reference.
     - Optional: upload a Regional Mapping CSV (state/province -> region).
       This is required if you want the Regionwise and Percentage Change
       plot galleries — a sample mapping file is available to download or
       load directly.

  3. Plot Options
     - Once your model configuration and data are ready, click "Create
       Plot" to build the heatmap galleries. After that, editing the
       legend bins (see each tab's "Gallery Defaults") updates the plots
       live — you don't need to click "Create Plot" again for legend
       changes.

  4. Downloads
     - Choose an output type from the dropdown:
         • Download Customized HTML — applies your live plot customisations
         • All Plots — every generated chart
         • Processed Data — the cleaned/underlying dataset
         • Everything — bundles both legend configurations as JSON plus the
           customized HTML report
     - Click "Download Selected Output".

RIGHT PANEL TABS
  - Processed Data — a preview table of the cleaned dataset behind the
    plots.
  - Regionwise — heatmap gallery grouped by region (needs the Regional
    Mapping file).
  - Statewise — heatmap gallery grouped by state.
  - Percentage Change — heatmap gallery showing percentage change between
    model versions (needs 2 versions and, for regional views, the mapping
    file).

LEGEND CONFIGURATION MANAGER
  Each gallery tab includes "Gallery Defaults" controls where you can:
    - Hand-edit the legend bins and colours.
    - Auto-generate quantile bins straight from the current data.
    - Import or export a legend configuration as JSON, so you can re-use a
      colour scheme across sessions or share it with a colleague.
  Relative AAL (Regionwise/Statewise) and Percentage Change each have their
  own, independently configured legend.

PLOT CUSTOMISATION
  Every plot can be adjusted for size, text sizing, legend behaviour, and
  data-label display; hover over any heatmap cell to see its exact relative
  AAL or percentage change value.

7. MODULE 4 — SECONDARY MODIFIER
================================================================================
PURPOSE
  The analytical core of the app: ingests extracted AAL data and computes
  relative loss-cost sensitivity by modifier, state, and line of business
  (SFD = single-family dwelling, COM = commercial), then renders a full,
  fully-customisable gallery of charts.

WHAT "CREDIT" AND "PENALTY" MEAN
  Secondary modifiers are shown in a credit/penalty format:
    - Credit: the modifier reduces average annual loss (AAL) versus the
      unknown/baseline case.
    - Penalty: the modifier increases AAL versus the unknown/baseline case.

LEFT PANEL — SIX-STAGE WORKFLOW
  1. Model and Exposure Settings
     - Vendor model family, Country code, Peril, Subperil, Suffix.

  2. Inputs
     - Upload three files: State AAL, Country AAL, and the SecMod mapping
       file (.rds or .csv — all three are required).
     - Sample versions of all three are downloadable, or click
       "Load Demo Data" to populate everything at once.
     - Click "Analyse Input" to process the uploaded/sample data.

  3. Credit / Penalty
     - Click "Generate Credit / Penalty plot" to build the country-wide
       chart showing which modifiers move loss cost by more than 10%,
       split into credits and penalties.

  4. State Sensitivity
     - Click "Generate all State plots" to build one chart per state
       comparing SFD vs COM. This renders every state individually, so it
       can take a little while.

  5. Individual Modifier
     - Click "Generate all modifiers plots" to build one chart per modifier
       category (e.g. roof covering, exterior wall type) comparing SFD vs
       COM across every state.

  6. Report
     - Once Stages 3–5 have plots you're happy with, click
       "Generate Report", then "Download Report" to get a customized HTML
       report that reflects your exact styling choices (this report is
       separate from — and in addition to — the shared Cart export).

PER-PLOT CUSTOMISATION (available on every chart in Stages 3–5)
  Click the sliders icon on any plot card to open its override panel:
    - Plot Layout: width, height, DPI, transparent background, plot title
      size, and (where relevant) facet/state-name label size.
    - Axis Properties: axis text/title size, x-axis label angle and
      spacing.
    - Legend & Panel Properties: show/hide legend, legend text and key
      size, panel spacing between facets.
    - Colour Properties: SFD/COM colours (State Sensitivity & Individual
      Modifier) or Penalty/Credit colours, depending on the chart type.
  Each gallery also has a "Gallery Defaults" bar at the top — set your
  preferred styling once, click "Apply to all N plots" to push it to every
  chart in that gallery, or "Add all N plots to Cart" to save the whole
  gallery in one click.
  Every plot card also has a download icon (saves that single chart) and a
  cart icon (adds that single chart, at its current styling, to your Cart
  with room to add commentary).

RIGHT PANEL TABS
  - State AAL / Country AAL / SecMod File — previews of your three inputs.
  - Min / Max Table — the country-wide credit/penalty range table.
  - Credit / Penalty — the generated chart.
  - State Sensitivity — the full per-state gallery.
  - Individual Modifier — the full per-modifier gallery.

TYPICAL WORKFLOW
  1. Set model/exposure settings.
  2. Upload (or load demo) State AAL, Country AAL, and SecMod mapping data,
     then Analyse Input.
  3. Generate the Credit/Penalty plot.
  4. Generate State Sensitivity plots.
  5. Generate Individual Modifier plots.
  6. Style any plots you want to keep, add the best ones to the Cart.
  7. Generate and download the customized Secmod report, and/or head to the
     Cart to build a combined report with items from other modules too.

8. CART & REPORTS
================================================================================
PURPOSE
  A single collection point for anything you've saved from any module —
  Vulnerability Sensitivity, Secondary Modifier, or elsewhere — so you can
  review it all together and export one combined report.

WHAT YOU'LL SEE
  - "Saved Items" summary with a running count of everything in your cart.
  - Each saved item shows a plot thumbnail, its written commentary, and a
    remove button.
  - "Remove All" clears the entire cart (with a confirmation prompt).

EXPORTING
  1. Choose a format from the dropdown: PowerPoint (.pptx), Word (.docx),
     or HTML (.html).
  2. Click "Generate Report".
  3. The file downloads automatically once it's ready.

WHAT EACH FORMAT LOOKS LIKE
  - PowerPoint (.pptx): a branded widescreen (16:9) deck — title slide,
    chunked contents/index slides, then one plot slide and one commentary
    slide per cart item, each with a progress indicator and item counter.
  - Word (.docx): a title page, an auto-updating table of contents, and one
    numbered section per cart item with a captioned figure and an indented
    commentary block.
  - HTML (.html): a single, self-contained page with a masthead, a static
    left-hand table of contents, and each item's plot and commentary in
    the same order as the other two formats.

Your cart persists for your session (and, depending on configuration, may
be saved to disk between sessions) so you can keep adding to it as you move
between modules before generating your final report.

10. TIPS, DEFINITIONS & TROUBLESHOOTING
================================================================================
KEY TERMS
  - AAL: Average Annual Loss.
  - SFD / COM: Single-Family Dwelling / Commercial occupancy.
  - EDM / RDM: Exposure Data Module / Result Data Module (RMS database
    types).
  - TSE / TSR: Verisk's equivalent exposure/result store naming.
  - Credit / Penalty: a modifier's effect on AAL relative to the unknown
    case — see Section 7 for the full definition.

GENERAL TIPS
  - Work through the numbered stage cards top to bottom in each module —
    later stages usually depend on earlier ones being marked "Done".
  - Use the sample data buttons first if you're new to a module; they let
    you see the expected file format and try the full workflow before
    connecting real data.
  - Read the lightbulb hint boxes next to form fields — they explain
    exactly what's expected.
  - You can add individual plots to the Cart as you go rather than waiting
    until the very end of a module.
  - Gallery-wide styling changes only take effect after clicking
    "Apply to all N plots" in that gallery's "Gallery Defaults" bar.

TROUBLESHOOTING
  - "Create Plot" / "Analyse Input" seems to do nothing: check the status
    badges on earlier stage cards — a Pending badge usually means a
    required input or setting is still missing.
  - Legend/colour changes aren't showing up: make sure you're editing the
    correct tab's Legend Configuration Manager (Relative AAL and Percentage
    Change have separate legends) and that you've applied the change.
  - Regionwise or Percentage Change tabs aren't appearing: these need a
    Regional Mapping file to be uploaded (or loaded from sample) and, for
    Percentage Change, two model versions.
  - Database connection fails in Result Extraction: confirm the server
    name/credentials for the chosen vendor and that the Exposure/Result
    databases you selected actually contain the ExposureSet/ResultSet IDs
    you entered.
  - Download button stays greyed out: some downloads (e.g. the Secmod
    customized report) unlock only after you click the matching
    "Generate" button first.
